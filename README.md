# AILURONE

A 2D action platformer built in Unity (C#) as a university group project at Asia Pacific University. The game was inspired by the demo game CICADAMATA, with influence from SUPERHOT.

## About
Player has to find their way to the final exit gate in order to escape from this sci-fi world. This could be challenging but the journey would be fun.

## Features
- Action platforming built around shooting, movement, etc.
- Multiple levels with a level select screen and **save system** that remembers unlocked levels
- Puzzle-based level design using bounce pads, shooting, target switches, moving platforms, pressure plates, enemies, collectible cores, timed gates, and teleport portals
- Full UI flow: Level Complete, You Win, and Game Over screens
